# JSX
리엑트. js 라이브러리고 상태관리 및 가상돔을 사용해서 화면 재빌드를 최소화 해준다.

원리를 좀 알아봤는데.

일단 리엑트는 js랑 xml을 짬뽕 시킨 js확장 문법 JSX를 사용해. 필수는 아니야. 아무래도 쓰는 게 좋아. 왜냐면 리엑트는 JSX를 js 객체로 바꾸고, 이걸 기반으로 가상돔을 만들고 실제 html을 그리거든.

```
// JSX: <div class="hi">Hello</div>
// 변환된 객체 (가상 DOM)
{
  type: 'div',
  props: {
    className: 'hi',
    children: 'Hello'
  }
}
```
이해되지?

우리가 html을 작성하면 안 돼. 단지 설계도를 넘기는 거야. 실제 html을 만드는 건 리엑트가 하고. 리엑트가 모든 요소를 책임지기 때문에 재빌드도 최적화 해주고 상태관리도 할 수 있는 거지.


JSX를 쓰면 바벨 등 트랜스폼을 써서 컴파일 단계에서 js 객체로 자동 변환해 주지만, JSX를 안 쓰면 라이브러리에서 제공하는 React.createElement메서드로 설계도를 하드 코딩해야 해. jQuery 느낌으로 생각해야 해. jQuery 문법만 지키면 모든 브라우저 대응이 되잖아. 쓰는 게 무조건 이득이야.
