# 리엑트는 라이브러리
리엑트는 프레임워크가 아니고 라이브러리야. 특정 관심사를 해결하기 위해 만들어졌어. UI지. 리엑트하면 재빌드, 상태관리잖아.

어째튼 라이브러리고 html에 붙여줘야 해. 리엑트 스스로는 존재할 수가 없어. 어케하는지 알려줄게.

``` html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <link rel="icon" type="image/svg+xml" href="/vite.svg" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>my-app</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.jsx"></script>
  </body>
</html>
```
이렇게 한단다.

리엑트 원리가 머야. 가상돔이랑 실제돔을 비교하고 업데이트 치는 거지. 실제돔이나 가상돔이나 결국 트리구조야. 시작 루트가 필요해. 보통 이렇게 해. indexl.html에서 div 하나를 루트로 잡는 거야. 그리고 그 안에 쭉 컴포넌트들을 배치하면서 트리를 완성하는 거지.

``` js
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import './index.css'
import App from './App.jsx'

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <App />
  </StrictMode>,
)
```

react-dom/client 라이브러리에서 제공하는 createRoot 메서드로 JSX로 만든 컴포넌트를 연결하면 끝. 이제부터 이 컴포넌트(그 안에 컴포넌트까지 전부 포함해서)는 리엑트가 관리하는 거야. 우리는 여기 직접적으로 html을 작성하면 안 되고 JSX 문법에 맞게 설계도만 넘겨야 해.
